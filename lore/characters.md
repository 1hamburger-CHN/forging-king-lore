## 铁 / Ferranthus

- **称号**：王锻 / ForgeKing
- **时代**：远古纪元（起源之火发现后第十代）
- **身份**：锻乡第十代传人、第六任锻造大师，唯一锻出四柄神珍之人
- **性别**：男
- **年龄**：50岁（故事发生时）
- **外貌**：身材魁梧，身高约1.9米，黑发，棕瞳。左手天生六指（与第一任锻造大师相同，此特征在血脉中沉睡了数万年）。双手布满厚茧，常年咳嗽（炉火熏蚀），背部微驼但骨架宽大，站定时依然让人仰视
- **性格**：对手艺近乎偏执的追求；固执到不近人情，宁断不弯；唯独以神珍换百姓性命时，他弯了——最有资格傲慢的人，做了最谦卑的交换
- **着装**：粗麻工装，皮围裙不离身
- **关联区域**：锻乡
- **关联故事**：王锻（wangduan）
- **关联器械**：神珍西洋剑（由地狱火石锻造，攻防一体）
- **关联资源**：地狱火石
- **现状**：被游牧族带走，死于何年何月、葬于何处无人知晓

- 接受了铁的交换条件，带走铁与神珍西洋剑

## 镭 / Radianthus

- **称号**：探险家 / Explorer
- **时代**：中世纪（公元1453年）
- **身份**：锻乡六指血脉当代传人，铁的血脉后人，铁匠学徒
- **性别**：男
- **年龄**：13岁（故事发生时）
- **外貌**：十三岁少年，身形偏瘦灵活，黑发。左手天生六指，多出的第六指极其灵活，对魔力震动感知极敏锐
- **性格**：机灵滑头、嘴硬心软、求生欲极强；表面吊儿郎当，实则重情义、有担当，危难中能保持铁匠般的冷静与狠劲
- **着装**：破旧麻布短褐，腰间别带锯齿的破断刃，右臂常缠半截断裂铁镣锁链
- **关联区域**：锻乡（逃出后流浪，途经火神山、青丘）
- **关联故事**：双生（shuangsheng）、探险家笔记：全卷（tanxianjiabiji）
- **关联器械**：幻溟之蝶吊坠
- **关联资源**：起源晶石、幽寒石
- **现状**：带着幻溟之蝶吊坠离开青丘，独自踏上未知旅途

## 玛卡·玛哈 / Maka & Maha

- **称号**：蝶变双子 / Twin Butterflies
- **时代**：中世纪（公元1453年，真实存世久远）
- **身份**：青丘幻溟之蝶，一体双生——玛卡执掌生命法则，玛哈执掌死亡法则
- **性别**：女
- **年龄**：外貌十五六岁（真实年龄未知，一体双生）
- **外貌**：外貌十五六岁少女，黑发长及脚踝，赤足。白昼玛卡翠绿眼眸、藤蔓白花长裙；黑夜玛哈纯黑无眼白眼眸、苍白皮肤、深紫嘴唇、黑蝶萦绕
- **性格**：玛卡温柔仁慈、心怀歉意；玛哈冷漠高傲、暴戾残忍，视人类为虫豸，却在长夜中对镭渐生一丝认同
- **着装**：玛卡着藤蔓与白花编织的长裙；玛哈着繁复华丽的暗黑长裙，裙摆如灰烬般破损
- **关联区域**：青丘
- **关联故事**：双生（shuangsheng）
- **关联资源**：起源晶石
- **起源与演变**：坦普拉覆灭后，坎迪拉以深渊能量与青丘生命力点化出两只彼此独立的蝴蝶，分别成为玛卡与玛哈。此后数百万年间，青丘自身魔力持续衰减，诡异花园研究黑魔法又引发瘴气；两股压力共同打破生死平衡，迫使两只蝴蝶融合为一具躯体，形成后世所见的“一蝶两生”。
- **现状**：青丘生机恢复，双生幻溟之蝶重归生死平衡

## 黑曜石 / Obsidian

- **称号**：大盗 / The Great Thief
- **时代**：中世纪（公元1453年）
- **身份**：斯科塔林大陆奴隶贸易寡头，地下组织“打铁人”头目
- **性别**：男
- **年龄**：40多岁
- **性格**：心狠手辣、冷酷无情、深不可测
- **背景/事迹**：横跨斯科塔林大陆的奴隶贸易寡头。他并非单纯的流寇，而是与【尼福尔海姆】极权统治阶级有着直接利益合作的“国家级黑手套”。其麾下的“打铁人”主要伏击锻乡商队与逃亡者（将极耐高温的铁匠作为极寒矿区最抢手的重劳力），同时也会大肆绑架斯科塔林大陆东部西北区域（如流金平原）出来的商人和旅徒。对于他庞大的奴隶帝国而言，在火神山跑掉一两个小学徒不过是无足轻重的日常损耗。
- **所属区域**：尼福尔海姆
- **活动范围**：火神山山麓（伏击点）、尼福尔海姆（贸易终端）；奴隶贸易网络横跨斯科塔林大陆。活动地点不改变其地域归属。
- **关联故事**：探险家笔记（tanxianjiabiji）
- **现状**：在火神山山麓伏击镭等人，后因忌惮青丘迷雾而撤退，继续在大陆上掌控其庞大的奴隶帝国。

## 坎迪拉 / Candela

- **称号**：大魔法师 / The Grand Mage
- **时代**：出生于坦普拉覆灭前36年，历经大断层时代，于暮年离世。
- **身份**：魔法协会创始人、现代魔法控制论与世界医疗网奠基人、玛卡与玛哈的点化者。
- **背景/事迹**：
  - **苍黎出身与战争决裂**：出生于【苍黎公国】嘉禾城，是铁血公爵瓦莱里乌斯的幼子。八岁显露高维元素坍缩天赋后，被送入深渊高塔训练为军用魔法兵器；十二岁参加铁壁要塞决战，父亲战死，自己的右臂也遭到重创。战场经历使他彻底拒绝以杀戮定义魔法。
  - **坦普拉求学**：十五岁研读《深渊能量守恒》，十六岁进入坦普拉星穹学府，主攻【元素魔法控制论】，并与【莱恩·怀特博士】成为同窗。二十六岁完成《元素魔法控制与平衡论》后拒绝留任，返回北方，以早期“魔法会”参与战后生态与生产修复。
  - **青丘求法**：三十六岁时亲历坦普拉覆灭。为拯救遭高维辐射与饥荒摧残的北方，他带领学徒南下两年抵达【青丘】，并停留两年半。在独角兽王的启示下，他领悟的并非单一“治愈术”，而是让生命力与深渊能量共存的平衡之道，同时重塑了受损右臂。
  - **重建与封神**：归乡时，【大有王国】早已在坦普拉覆灭前的黄金十年建立，却已因灾变而名存实亡。坎迪拉率领魔法会平息战乱、净化辐射并重建医疗，帮助大有恢复和稳固政权，随后使流金平原诸自由城邦接受大有庇护。他将魔法会升格为中立的【魔法协会】，建立覆盖大陆的医疗与基建网络，晚年被尊为“大魔法师”。
- **关键人物关联**：
  - **莱恩·怀特博士**：坦普拉求学时期的同级挚友。怀特钻研水晶科技，坎迪拉钻研元素魔法，两人代表了旧时代最绝顶的智慧。
  - **玛卡与玛哈（双生幻溟之蝶）**：坎迪拉在青丘以纯粹生命力与深渊能量点化出两只独立的新生蝴蝶：玛卡代表“生”，玛哈代表“灭”。数百万年后，青丘魔力衰减与诡异花园黑魔法研究引发的瘴气共同迫使二者融合，成为后世的一体双生形态。

## 瓦莱里乌斯 / Valerius（铁血公爵）

- **称号**：铁血公爵 / The Iron Duke
- **时代**：远古纪元（坦普拉覆灭前36年至铁壁要塞决战时期）
- **身份**：苍黎公国北境最高统帅、瓦莱里乌斯家族领袖，坎迪拉的生父
- **性别**：男
- **年龄**：52岁（战死时）
- **性格**：冷血严苛，信奉极致暴力与战场功勋；视战争为唯一定律，视血脉亲情如兵器工具，不容忍任何软弱与迟疑
- **背景/事迹**：
  - 苍黎公国北境统帅，一生铁血治军，在北方兼并混战中立下赫赫威名。两个成年长子皆阵亡于惨烈的战壕血战中。
  - 八岁幼子坎迪拉展现出高维元素坍缩天赋后，他逼迫幼子当场融化家族重剑自证价值，随即冷血地将其送入深渊高塔打造成杀戮兵器。
  - 在铁壁要塞决战中久攻不下，下令十二岁的坎迪拉作为先锋强拆重铁城门。城破之时遭遇敌军深渊献祭反噬，连人带马被压缩熔铸为废铁，战死阵前。他的死成为坎迪拉彻底决裂杀戮战争的契机。
- **关联区域**：大有（嘉禾城 / 苍黎旧地）
- **关联故事**：大魔法师（damofashi）
- **关联人物**：坎迪拉（次子）

## 阿米娜 / Amina（女王）

- **称号**：女王 / The Queen（网站代号：女王）
- **时代**：中世纪（公元1445年左右）
- **身份**：明海宫法学院优异学子 → 明海宫法官兼大祭司 → 赫里奥斯先王真血遗孤、奥西斯新女王
- **性别**：女
- **年龄**：22岁（故事主线时）
- **外貌**：身形高挑健美，古铜色皮肤，深黑长发束成利落高马尾，深琥珀色瞳孔在光线下隐现暗金。面容沉毅冷艳，兼具神职大祭司的圣洁与严正法官的威仪
- **性格**：冷静果敢、刚毅坚决、恪守秩序公义；从法理严明的司法官到身负沙海存亡的女王，兼具坚定的铁血手段与深沉悲悯
- **着装**：身披织有砂金丝线的拉祖利白金教袍与轻型嵌皮胸甲，腰系沉重的法典铜锁链与制式佩剑，持有一柄可拆解为近身刺刃的「权标/刺刃」
- **关联区域**：奥西斯 / 玛加罗斯
- **关联故事**：王冢（wangzhong）
- **关联器械**：权标/刺刃
- **关联图书**：《拉祖利神圣法典》（沙海神圣法典）
- **关联野兽**：砂金巨兽（Boss）
- **关联资源**：砂金、黑油
- **背景/事迹**：
  - **明海宫法学院与法官生涯**：自幼在奥西斯圣城教廷修道院长大，以为自己是烈士孤儿。凭借过人天赋考入玛加罗斯明海宫法学院，精通神圣法典与权标格斗武技。毕业后任职明海宫法官兼大祭司，巡视盆地油井区，铁面无私惩治黑油盗采走私，深得民众拥戴。
  - **百年大典与巨像选召**：老国王病笃驾崩无嗣，教廷依律举行百年一度的盛大祭祀典礼。阿米娜作为大祭司主持祈祷时，千丈赫里奥斯巨像千年来首次迸发通天金光选召了她，证实其体内沉睡着先王唯一的正统真血。
  - **四日猎杀与暗夜送葬**：教廷内鬼主教勾结赫里奥斯地下情报组织【渡鸦】，重金雇佣精锐赏金猎人在圣城内疯狂追杀阿米娜。阿米娜凭借权标与刺刃在街巷黑油管道间极限周旋四日四夜，多次绝境反杀脱身。第四夜被忠诚元老密召入宫，为防内鬼走漏风声，阿米娜隐藏身份混入全由皇家卫队精锐与魔法师伪装的“先王送葬队伍”，次日清晨秘密出城。
  - **地宫终局与金色加冕**：在地底以启门铭文「以血破锁，燃渊中之火」开启封印大门，与重伤濒死的老守陵人法赫德合诵巨像唤醒铭文「日光不灭，沙海不死；先祖已逝，金石当生」，复苏六层楼高的砂金巨兽，以惩戒铭文「擅越圣疆，断骨剥肉；逆法典者，碾为黄沙」全歼入侵军团。战后返回圣城逮捕并严惩内鬼主教，正式加冕为奥西斯女王，为法赫德一族筑起金色塑像。
- **现状**：加冕为王，整肃玛奥边防与黑油防线，严防北方极寒军团再次渗透

## 法赫德 / Fahd（守陵人）

- **称号**：守陵人 / The Tombkeeper（网站代号：守陵人）
- **时代**：中世纪（公元1445年左右，实际存活数千年）
- **身份**：万王眠林末代守护者、拥有赫里奥斯王室血脉的半机械人
- **性别**：男
- **年龄**：外表如干涸枯木般沧桑（体内依靠机械心脏维持数千年机体运转）

## 伊瓦尔 / Ivar（霜骨）
